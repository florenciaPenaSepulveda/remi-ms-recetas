# remi-ms-recetas

Microservicio de recetas de Remi Recetas.

## Tecnologías

- NestJS
- TypeScript
- MongoDB (Mongoose)
- RabbitMQ / microservicios
- Jest

## Estructura

```
📄 README.md
📄 dockerfile
📄 eslint.config.mjs
📄 nest-cli.json
📄 package-lock.json
📄 package.json
📁 src
📄 tsconfig.build.json
📄 tsconfig.json
```

## Cómo ejecutarlo

```bash
npm install
npm run start:dev
npm start
npm run build
npm run test
```
